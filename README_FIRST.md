# Настройка проекта «Сканирование книг»

**Комплект управляющих файлов v1.1.0.** Внутри только инструкции и правила, исходные книги сюда не включены.

## Установка (один раз)

1. Создайте проект ChatGPT «Сканирование книг».
2. Откройте настройки проекта и поместите текст из **`PROJECT_INSTRUCTIONS.txt`** в поле инструкций проекта. Это важный короткий «запускатель» общих правил.
3. Добавьте файлы `00_MAIN.md` — `06_CHANGELOG.md` в источники/файлы проекта. `README_FIRST.md` можно хранить у себя и не добавлять: он предназначен для вас.
4. Не загружайте сами книги в источники проекта как постоянные правила; прикрепляйте каждую книгу в отдельном новом чате внутри проекта.

## Использование

- **Шаг 1:** отправьте в новом чате PDF. ChatGPT проводит диагностику **без OCR и без правок** и сообщает план.
- **Шаг 2:** если план устраивает, ответьте «Начинай». ChatGPT обрабатывает максимально возможный объём безопасно.
- **Шаг 3:** если готов только фрагмент, получите ZIP с частями и прогрессом. В том же или новом чате пишите «Продолжай»; если файлы недоступны, прикрепите исходную книгу и последний ZIP прогресса.
- **Итог:** получите один ZIP с исправленным PDF, кликабельным содержанием, двумя закладками «Содержание» и отчётом.

## Когда появляются новые правила

Если выявлено новое **проверенное** решение, ChatGPT должен сообщить об этом и приложить `PROPOSED_UPDATE.md` внутрь ZIP. Изменяйте постоянные файлы проекта только после проверки и вашего одобрения. После изменения обновляйте номер версии в инструкциях и в журнале изменений.

## Обновление с v1.0.0

Если прежний комплект уже загружен в проект: **замените** `00_MAIN.md` — `06_CHANGELOG.md` версиями из данного ZIP, не добавляйте вторые одноимённые копии. Замените текст в поле **«Инструкции проекта»** целиком содержимым нового `PROJECT_INSTRUCTIONS.txt`, не дописывайте поверх старого. `README_FIRST.md` можно хранить вне источников.

Новое: при первой диагностике читается предыдущий XMP-паспорт BookScan (без OCR); после успешной обработки итоговый PDF получает паспорт и, если возможно безопасно разместить, одну светлую вертикальную метку `BookScan · v1.1.0` посередине правого края последней страницы. При занятом месте метка **пропускается без переноса**. Она лишь указатель происхождения, не сертификат качества; метаданные могут быть изменены. Исходный файл не переписывается.

Версия правил **не является** версией OCR-движка. Иной номер версии сам по себе не повод заново сканировать PDF. Итоговый SHA-256 хранится в отчёте ZIP, а не внутри самохешируемого PDF.

## Что гарантируется, а что нет

Комплект подробно определяет ожидаемое поведение, но не устанавливает программы OCR, не запускает задачи сам по себе и не создаёт общий диск прогресса между чатами. Качество OCR зависит от исходного изображения, реальных инструментов и возможности сверить сложные участки. Неудачную проверку следует честно отражать в отчёте.

## Состав комплекта

- `PROJECT_INSTRUCTIONS.txt` — скопировать в инструкции проекта;
- `00_MAIN.md` — основной протокол и команды;
- `01_DIAGNOSTICS.md` — первый ответ, диагностика без OCR;
- `02_PROCESSING.md` — стратегии восстановления и скорости;
- `03_QUALITY_AND_TOC.md` — проверка и все правила содержания;
- `04_KNOWN_PROBLEMS.md` — классы дефектов и накопление опыта;
- `05_PROGRESS_AND_DELIVERY.md` — ZIP, контрольные точки и продолжение;
- `06_CHANGELOG.md` — версия и регрессионные сценарии.
